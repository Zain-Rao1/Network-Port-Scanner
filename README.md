# Network Port Scanner

A beginner-friendly Python cybersecurity project that scans TCP ports on an IPv4 target and saves scan results to a text file.

## Features

- Displays computer name and local IP address
- Validates IPv4 addresses
- Validates port ranges (1–65535)
- Scans multiple TCP ports
- Identifies open and closed or unavailable ports
- Displays a scan summary
- Saves scan results to `scan_results.txt`

## Requirements

- Python 3
- No external Python packages required

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python Network-Port-Scanner.py
   ```

4. Enter the target IPv4 address.
5. Enter the starting and ending ports.

## Example

Use `127.0.0.1` to test your own computer.

The program displays the scan results and saves a report to `scan_results.txt` in the script's folder.

## Disclaimer

This tool is intended for educational purposes and authorized security testing only. Scan only systems you own or have explicit permission to test.
